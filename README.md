This repository contains a **Multi-Agent Research Assistant** designed to automate deep-dive research tasks using specialized AI agents. By leveraging a collaborative agentic workflow, the system can search the web, synthesize information, and produce comprehensive reports on any given topic.

## 🚀 Features
- **Collaborative Agents:** Uses multiple specialized agents (Researcher, Writer, Editor) to handle different stages of the research process.
- **Automated Web Search:** Integrated search capabilities to fetch up-to-date information from the internet.
- **Comprehensive Output:** Delivers structured, high-quality research reports in Markdown format.
- **Powered by LangGraph/LangChain:** Built on modern agentic frameworks for robust state management and task delegation.
