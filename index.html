agents.py components

Four focused research agents.

These blocks mirror the useful functions in agents.py: search, summarize, retrieve memory context, and write the final report.

Step 01

Searcher

Calls Tavily with the requested source count and normalizes each result into title, URL, and content fields.

TavilySearchResults search_results
Step 02

Summarizer

Uses Groq to compress each source into a short summary that can be passed safely into the report writer.

ChatGroq summaries
Step 03

Context Retriever

Fetches Zep graph context for the user so the report can account for remembered project knowledge.

Zep graph zep_context
Step 04

Writer

Combines the topic, retrieved context, and source summaries into a formal final report.

ChatGroq final_report
